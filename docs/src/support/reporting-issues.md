# Reporting issues

If you found an issue in `easepick2`, please report it.

All issues should be reported in the [easepick2 repository](https://github.com/YuaFox/easepick2) on GitHub.

Things to keep in mind:

* Search for existing issues before starting a new one.
* Be concise and informative, making it easy to understand the problem.
* Feel free to jump into discussions around issues!
