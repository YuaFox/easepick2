# Development environment

The main package's GitHub repository hosts [all easepick2 sub-packages](https://github.com/YuaFox/easepick2/tree/master/packages).

## Requirements

- Node.js ^14.0.0
- npm 7+
- Git

## Setting up the development environment

```bash
git clone https://github.com/YuaFox/easepick2.git
cd easepick2
npm install
```

## Running tests

```bash
npm test
```

## Creating a build

Development version:

```bash
npm run dev
```

Minified version:

```bash
npm run prod
```
